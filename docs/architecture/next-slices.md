# Remaining Scope

## Delivered, not roadmap

- MatchReview, the internal canonical timeline, goalkeeper projection, statistics warnings, and client PDF export are delivered. See [../README.md](../README.md).
- The warnings panel is the discrepancy workflow. Do not add a separate reconciliation-resolution UI without a new product decision.

## Future candidates

| Candidate | Boundary |
|---|---|
| Revision history | Requires backend persistence and API support for confidence, visibility, corrected payload, `revision_of`, and chronological diffs. Current responses are latest-only. |
| Public reports | A Google Sheets/GitHub Pages projection is future scope only. It must be separate from the authenticated canonical timeline. |
| Expanded tactical analytics | Pivot-specific zones, passing accuracy, heatmaps, and opponent libraries require an approved data contract. |
| Quality hardening | E2E coverage, coverage thresholds, and performance testing remain separate hardening work. |
